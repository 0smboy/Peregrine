日期 2026-08-05 · 集群 VIP https://10.0.0.10:8085（自签 TLS）· 计划权威：生产剩余任务规划（审计修订版）· 未宣称 PRODUCTION-GO-LIVE

一句话结论：盘腾开了，监控进面板了，Keystone 与 TLS 在实验室级绿灯，S3（含 EC2）能打通，Python 三节点对照集群也装上了。 但整条链路仍是 LAB-READY：有 soak 毛刺、func 未满 54、L3b 未做生产停线、证书是自签、四节点 Python 没做。 可以继续公平测试与联调；不能拿今天的证据对外写「生产上线完成」。

1. 故事线：我们实际经历了什么

起点很糟：数据盘几乎满（swift1 d1 一度 100%）。大家以为 swift delete -a 就能腾空间，结果只删掉约 128 个「还能 HEAD 到的」活对象；盘上仍有几十万孤儿 .data 和数万墓碑。reclaim_age=600 也没在 10 分钟内把墓碑清掉——后来证明 replicator 一度根本不读配置里的 reclaim_age。

真正腾盘靠的是 A+B：强制扫墓碑 + 按（修好后的）hash 对账清孤儿。四节点三盘从约 90% 掉到约 2%。对账脚本当初少写了一个斜杠，导致 kept_dirs=0，差点误判；根因修掉后，又清了幽灵容器和约 65 万僵尸 DB 行。

盘空之后，Identity 和监控才站得住。Galera×3 + Keystone 上了，VIP 加了自签 TLS，TempAuth 与 Keystone 共存。中间踩过：Mac 编的二进制扔 Linux 上 Exec format error、部署时 HAProxy 后端空了导致 soak 一串 503、keystoneauth 误给 TempAuth 请求盖章导致 list 401、Keystone s3tokens 坏 base64 直接把 uwsgi 打崩。这些都修了，证据都在。

最后 Rust 让出 d1，Python 三节点在 swift2/3/4 上以 venv 路径跑起来，和 Rust VIP 分盘分端口。阶段三「双实现」终于有了真实对照面，而不再是 FROZEN 空壳。

4. 分波说明（人性化）

腾盘与观测

delete -a 诚实结论是「API 清仓 ≠ 清盘」。墓碑指标 swift-recon tombstones、SQLite dbspace/vacuum 先做了 CLI，后接到 Prometheus textfile 与 Grafana；告警含墓碑增长、freelist、盘压。Grafana 渲染截图仍有 stub，但查询可用。

Identity 与 TLS

MariaDB Galera 三节点 + Keystone，Fernet 同步。切管道时做过 TempAuth 回滚演练（PARTIAL：有一次窗口撞上 proxy 503）。TLS 是自签 CN=VIP，够 lab；生产要运营证书才能改标签。

拓扑 spp / Region

对象环重建到每盘端口 6210+，避免和 A/C 的 6201/6202 撞车；标签 r1=swift1/2、r2=swift3/4，只是环亲和，不是跨城灾备。1h soak：185 成功 / 7 失败——其中一串 503 是并发部署错误架构二进制导致后端空窗，不是 spp 本身坏了。

S3

ListMPU、MPU、MultiDelete 等单元停线补齐后，VIP 上 TempAuth SigV4 与 EC2→Keystone s3tokens→S3 都通了。路径上修过：s3tokens 崩溃、Rust 不认识 EC2 key 就直接 InvalidAccessKeyId（现已 defer 到 Keystone）。L3b 多节点 quorum 与 4KB KEEP 没有用今天的数据宣称。

Python 对照

阶段三终于解冻：Rust 退出 d1，Python 三节点用 venv（RPM 被 pyxattr 卡住）。CRUD 在三台上从内网验证通过。四节点故意没做：swift1 继续当 client/monitor 更干净。本机直连 :8090 可能空回复（防火墙），请从 swift1 或内网打。

6. 明确还没做完的事

  • PRODUCTION-GO-LIVE：运营 PEM、soak fail=0、Keystone/EC 完整 func 门禁、L3b 生产停线
  • proxy 需 --features ec 重编部署（当前 EC 501）
  • TempAuth 与 Keystone 并存下的「经典 54/54」叙事要改成 Keystone 原生套件或修好共存语义
  • Python 四节点；本机访问 Python API 的网络策略
  • Keystone 站点包 s3tokens 补丁：RPM 升级后要重打
  • container-sync / 真跨站多 Region：保持 wont fix / 非宣称

7. 建议你怎么用这些结果

  1. 公平测试：Rust VIP HTTPS vs Python :8090（内网），分表报告，不要混入口。
  2. 联调 S3：TempAuth 或 EC2+Keystone 均可；记着用 curl -k / 信任自签。
  3. 别升级标签：对外仍写 LAB / CORE-PATH / 分波 PARTIAL，直到生产硬门勾完。
  4. 下一刀优先：EC 特性二进制 → 干净 soak → 运营证书 → L3b 多节点，或按需开 Python 四节点。
