4. 契约与公平轨道

契约层级

  • L1 Public Swift v1 — Mandatory
  • L2 Middleware — feature-dependent；unsupported ≠ FAIL
  • L3 Backend protocol — 仅声明 drop-in 时强制
  • L4 On-disk/ops — 同上

公平轨道

  • ISO-CONFIG — knobs 交集 + 有效并发/CPU 配额对齐
  • ISO-RESOURCE — 同配额，允许实现特有调优
  • Rust workers*max_clients→≤128 threads ≠ Python prefork
