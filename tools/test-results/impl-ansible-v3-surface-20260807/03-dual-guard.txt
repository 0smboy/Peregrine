#
# Operator workflow:
#   1) Prepare new disk out-of-band (mount XFS at /srv/node/<name>) OR add a

#        - add host to storage groups with region/zone/swift_devices (add-node)
#   3) Apply: swift-deploy apply … --playbook expand.yml

# Dual-guard: never mkfs / wipe /srv/node. Expand mode never rm's existing
# *.ring.gz; it idempotently adds missing devices then rebalances.

# device list (no replica2part2dev persistence) — expect partition moves;
# replicators heal. Schedule during a maintenance window.
