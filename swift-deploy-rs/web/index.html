01

部署方式与基础设施

决定这是生产集群还是 SAIO 测试环境，并提供部署机连接集群所需的基础参数。

02

节点与角色

每台必填节点名、SSH 地址、首次端口、root 私钥和至少一个角色。生产集群还必须覆盖 proxy、account、container、object 和时间同步。

proxyAPI 入口 account / container / objectSwift 元数据与对象存储 keystone / mariadb本地认证服务 haproxy / keepalived高可用入口
03

网络、故障域与磁盘

每台必填管理、存储和业务 IP；存储节点再填真实故障域、系统盘和全部数据盘。Region/Zone 必须对应真实机房、机架或电源边界，不能为通过校验随意编号。

管理网SSH、软件源、NTP
存储网读写、复制与 rsync
复制地址v3 锁定为存储 IP
业务网Proxy / VIP 对外入口
04

Ring 与存储策略

Account、Container 与默认 Object Ring 使用同一组基础参数，设备来自上一步明确列出的数据盘。

05

Keystone 认证与访问入口

浏览器不保存密码；生成配置后，密码会写入部署机 0700 工作区内的 0600 group_vars 文件，刷新页面不会删除该工作区。

认证配置

所有认证密码至少 12 位，只能使用英文字母、数字和 . _ ~ -，不能含空格或其他符号。

入口与高可用

当前 v3 合同没有端到端 TLS，且对象静态加密被关闭。只能部署在可信隔离网络，或在外部可信入口终止 TLS；不能把 HTTP 端口直接暴露到不可信网络。
