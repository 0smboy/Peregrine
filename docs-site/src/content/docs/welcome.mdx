Peregrine is a production object-storage platform built around a **ground-up
Rust rewrite of [OpenStack Swift](https://github.com/openstack/swift)**. Every
on-disk and on-the-wire format is **byte-for-byte compatible** with Python
Swift, so a Peregrine binary can be dropped onto a node in a live Python cluster
and validated one component at a time. The repository ships everything needed to
run the system in production: the storage engine, a Python-free deployer, a load
generator, a benchmark harness, and a web console.

<Aside type="note" title="Format fidelity over everything">
Swift's correctness lives in its formats — the ring, the account and container
SQLite databases, the on-disk diskfile layout, pickled hashes, crypto metadata,
HMAC signatures, and erasure-coded fragment archives. Peregrine reproduces each
one exactly, proven against the real Python implementation as a golden oracle.
That is what makes a node-by-node rollout safe rather than a big-bang rewrite.
</Aside>

## Status

The data path is feature-complete and byte-compatible with Python Swift:
replication and erasure coding, all four servers, every consistency daemon, the
middleware pipeline, and container sharding. The workspace runs ~946 tests, and
the system has been validated live on a four-node high-availability cluster —
functional parity against Python, sustained load, and node-down failover. See
[Testing](/testing) and [Performance](/performance) for the numbers.
