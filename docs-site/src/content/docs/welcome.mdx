Peregrine is a Rust-first object-storage engineering platform built around a
**ground-up Rust rewrite of [OpenStack Swift](https://github.com/openstack/swift)**.
It targets byte compatibility on implemented, explicitly tested paths. It is an
advanced lab system, not a feature-complete Swift twin or a production drop-in
replacement.

<Aside type="note" title="Format fidelity over everything">
Swift's correctness lives in its formats: the ring, the account and container
SQLite databases, the on-disk diskfile layout, pickled hashes, crypto metadata,
HMAC signatures, and erasure-coded fragment archives. Peregrine uses Python
Swift as the oracle for scoped golden and live proofs. Consult the strict parity
matrix before planning any mixed rollout.
</Aside>

    workspace. [Read more →](/swift-rust)

    A bounded, Python-free deployer that executes the upstream Swift Ansible v3

    authorization. [Read more →](/swift-deploy-rs)
  </Card>
  <Card title="cosbench-rs">
    A Rust rewrite of Intel's COSBench core: an S3/Swift load generator with
    prepare / main / cleanup workloads and JSON/CSV reports. [Read more →](/cosbench-rs)
  </Card>
  <Card title="autocos">
    Benchmark automation over cosbench-rs — submit workloads, track progress,
    collect and archive results. [Read more →](/autocos)
  </Card>
  <Card title="swift-console">
    The web console: a files browser, deploy control, live monitoring, and a
    chaos / HA lab, served from a single Rust binary. [Read more →](/swift-console)
