This page is the public, **strict** comparison of Peregrine `swift-rust` to
upstream OpenStack Swift. **Partial implementation is treated as not
implemented.** Product and fairness claims must stay inside what is green here.

Canonical long form in-repo:
[`docs/fairness-lab/RUST-VS-PYTHON-PARITY.md`](https://github.com/0smboy/Peregrine/blob/main/docs/fairness-lab/RUST-VS-PYTHON-PARITY.md).

**As of 2026-08-08 · Contabo lab · LAB-HARD-GREEN · not PRODUCTION-GO-LIVE.**

## Headline

| Area | Status |
|------|--------|
| Swift v1 core CRUD + common middleware | **Mostly implemented** |
| TempAuth + Keystone lab + EC + S3 core/MPU + bulk upload | **Implemented (lab-proven)** |
| S3 SigV4 surface: chunk-sig, multi-version, lifecycle Transition exec, WORM, ACP store+enforce, local IAM dir | **Implemented (unit ~204)** |
| OpenStack-standard Paste names + xprofile / list_endpoints | **Implemented (wired)** |
| process_workers prefork + SLO concurrent HEAD / listing etag refetch | **Implemented (unit)** |
| Multi-node container sharding product KEEP / multi-cluster sync / operator PEM | **Not implemented** (strict) |
| SigV2 / KMIP / unlimited third-party Paste plugins / AWS IAM cloud | **Not implemented** (or WONTFIX) |
