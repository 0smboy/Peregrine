This page is the one-page contract for a **named tenant** on the
implemented S3 / Swift subset. Stance: **IMPLEMENTED_SUBSET_ONLY**.
It is not a drop-in for every S3 client, and it is not a Swift twin.

<Aside type="caution" title="Lab contract, not a production go-live">
Live proxies and the VIP run Guard (`3d0138d5…`,
[releases](/releases)). Stance remains **IMPLEMENTED_SUBSET_ONLY**.
49/8 is the acceptance pass, not GREEN. Gate `671bcbaf…` is the
rollback copy on each node.
</Aside>

Scoreboard evidence: post-GUARD
`strict-s3-dual-20260818-postguard.json` (2026-08-18, SHA-256
`52588c82…`), failing set identical to post-GATE (`50f0c860…`). Method:
[Dual-oracle](/dual-oracle). Client behavior: [S3 API](/s3-api).
Claim boundary: [parity](/parity).

## Rust extras (kept)

These stay implemented. They are **not** turned into `501`. They are
**not** a Python-parity PASS on the frozen 57 (seven of the eight
residuals). Second scoreboard: `tools/strict-s3-supplement.py`.

| Extra | Rust behavior |
|-------|----------------|
| Object ACL write `?acl` | 200 |
| Bucket tagging write `?tagging` | 200 |
| Object tagging delete `?tagging` | 204 |
| Bucket CORS GET / PUT / DELETE | 200 / 200 / 204 |
| RestoreObject `?restore` | honest `400 InvalidObjectState` while cold routing is off |
